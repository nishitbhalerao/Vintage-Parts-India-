================================================================================
                            QUICK START COMMANDS
================================================================================

CLONE REPOSITORY:
  git clone https://github.com/nishitbhalerao/Vintage-Parts-India-.git
  cd Vintage-Parts-India-

INSTALL DEPENDENCIES:
  cd server && npm install
  cd ../client && npm install

CREATE ENVIRONMENT FILES:
  server/.env:
    PORT=5000
    MONGODB_URI=mongodb://127.0.0.1:27017/vintagepartsIndia
    JWT_SECRET=your_secret_key
    NODE_ENV=development

  client/.env:
    VITE_API_URL=http://localhost:5000/api

START SERVERS:
  Terminal 1 (Backend):
    cd server && npm run dev

  Terminal 2 (Frontend):
    cd client && npm run dev

ACCESS APPLICATION:
  Frontend: http://localhost:3000
  Backend API: http://localhost:5000
  Admin Panel: http://localhost:3000/admin

================================================================================
                            TROUBLESHOOTING
================================================================================

MONGODB CONNECTION ERROR:
  Solution: Make sure MongoDB is running
  - Windows: Run 'mongod' in terminal
  - Mac: brew services start mongodb-community
  - Linux: sudo systemctl start mongod

PORT ALREADY IN USE:
  Solution: Kill process using the port
  - Windows: netstat -ano | findstr :5000
  - Mac/Linux: lsof -i :5000

DEPENDENCIES INSTALLATION FAILED:
  Solution: Clear cache and reinstall
  - npm cache clean --force
  - rm -rf node_modules package-lock.json
  - npm install

FRONTEND NOT LOADING:
  Solution: Clear browser cache and hard refresh
  - Ctrl+Shift+Delete (Windows)
  - Cmd+Shift+Delete (Mac)

For more troubleshooting, see HOW-TO-RUN.md
